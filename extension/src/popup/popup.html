LinkedIn MCP Bridge

Extrai dados do LinkedIn do seu navegador autenticado para o servidor MCP.

Desconectado

URL MCP para configurar na IA:

http://127.0.0.1:8000/mcp

Cole essa URL em seu cliente MCP (Claude Desktop, Cursor, OpenCode, etc.).

Status do Bridge

Bridge URL: ws://127.0.0.1:8765

Inicie o servidor com bun run src/index.ts (bridge ativo por padrão) e clique em Conectar.

Como usar

  1. Mantenha o servidor rodando: bun run src/index.ts
  2. Clique em Conectar Bridge nesta extensão.
  3. Configure a URL acima no seu cliente MCP como transporte streamable-http.
  4. A IA agora acessa o LinkedIn através desta extensão + servidor local.
